# 管理控制台重构（FD-02）

日期：2026-09-25。使用项目 frontend-design 技能；范围仅为管理台及两个管理操作确认，不改会话列表、基础会话与输入区。

## 设计计划与实施前审视

保留现有字体与五主题。清新白参考色：背景 `#f4f5f7`、导航 `#eaecef`、表面 `#ffffff`、正文 `#1f2937`、次要文字 `#6b7280`、强调色 `#10b981`；实现使用现有 theme token，不硬编码此参考色。代码与路径保持原文。

页面标题 22px（手机 21px）、区块标题 17px、记录名 16px、主要控件与说明 14–16px，辅助信息 12–13px。左对齐；每个集合只有一个表面，行之间用分隔线，编辑区独立。导航保持五个真实分区，手机以明确分区选择器进入。

```text
桌面：分区导航 | 标题、集合记录 | 按需编辑／只读会话
手机：分区入口 / 标题与主要动作 / 记录列表
                       编辑时：表单 / 保存与取消
```

审视最初想法：不做常见 SaaS 仪表盘，不新增统计大卡、趋势或健康标签。保留会话审计的 360px 列表宽度与既有分页/滚动合同；空详情只显示短说明而不铺满整列。项目记录改为名称、状态、完整路径、限额与工作详情权限的主次层级，避免手机重复表格表头。用户先显示用户名、邮箱与角色名，内部 ID 收入可展开详情。角色显示实际已有的项目授权位；不增加新的权限编辑能力。

## 实现与复审

- `admin-ui.js`：统一记录结构；项目路径完整换行；用户角色名与详情；角色授权内容；按服务概况、存储、请求指标、设备组织真实系统快照。运行时间显示天/小时/分钟并保留秒数，无样本延迟继续显示 `—`。
- `admin-ui.css`：独立管理台覆盖层，导航、标题、列表、表单、系统分区与手机触控规格统一。编辑器管理、资源管理与按需加载实现不变。
- `app.js` 两个管理 handler：删除用户与关闭团队模式改为主题内 `<dialog>`，取消获得初始焦点，Escape 取消，Tab 留在原生模态范围；取消不写入。确认后仍走既有 writer 与错误反馈，增加身份代次、管理员与当前用户检查。
- 确认文案依据 `HybridAuthStore.verifyToken`：关闭多用户会使团队令牌失效，可能需要单用户密码重新登录，不承诺当前账户一直有效。公开分享同样失效。

截图复审发现空会话详情仍被外层 grid 拉伸，已增加 `align-self: start`。项目与用户手机长路径/邮箱换行，保存按钮至少 44px 且可滚动到达；横屏保留空间允许的导航而不强制手机竖屏。

## 验证记录

测试与截图仅使用隔离的 `127.0.0.1:41763` fixture，全部用户、项目、设备与指标均为测试数据。没有生产写操作、提交、重启或部署。

- `public_ui.test.ts --test-name-pattern=admin`：31 项通过。旧项目表格结构断言替换为等价名称、完整路径、权限、操作与手机换行断言；功能与授权断言保留。
- `admin-correctness`、`admin-navigation` 与新 `admin-redesign`：覆盖保存失败/重复提交、草稿分离、迟到响应、资源重试、只读观察、分页、返回会话草稿、删除确认取消/键盘焦点/失败、确认中异步 401 清理身份与零写入、手机控件宽度、真实指标无样本状态。五视口运行 28 项通过、37 项按原用例范围跳过；另加身份过期确认回归 2 项通过。
- 浏览器初轮两个失败属于测试脚本：桌面竖屏错误使用桌面横屏入口；主题循环未等分区选择器挂载。已修正脚本，未修改产品规避断言。

证据目录：[管理台重构截图](2026-09-25-admin-redesign-evidence/)。既有测试截图重定向至此，不覆盖旧审计证据。单独主题矩阵针对 320px 用户编辑页，并不代表每页遍历所有主题/语言组合。

TypeScript 全仓类型检查由主代理执行。未验证真实 iOS/Safari/VoiceOver、真实手机键盘、生产团队令牌切换、全部主题对比度重新测量；原生 dialog 依赖当前支持它的浏览器。未声称性能提升。

## 回退

独立移除 `admin-ui.css` 注册与本次 admin renderer/两个 handler 改动即可回退视觉与确认，不涉及服务器数据格式或运行时迁移。不要回退其他代理或此前已存在的工作区改动。

## 生产静态资源链补查

Fixture 会直接读取 public 文件，不能证明生产 allowlist 已注册资源。后续补查发现 `DEFAULT_STATIC_SOURCE_FILES` 漏了 `boot-recovery.js`、`approval-ui.js/css`、`settings-ui.js/css` 与 `admin-ui.css`。已补允许清单，并使同一清单的自动路由同时支持 `.js` 与 `.css` MIME；其他路由与 API 鉴权不变。

关联 OPT-15、18、20：新资源进入构建 ID，继续复用原版本校验、有限压缩缓存与条件请求逻辑，不增加目录通配读取。`server_auth` 真实 HTTP 验证六资源的 200/MIME、同版本 immutable、旧版本 no-cache、Brotli/Gzip、ETag 304 与空响应；source 两项聚焦测试通过。生产 build smoke 另核对六资源正文确实来自 `dist/public`，不会误用 source public。未重启生产。
