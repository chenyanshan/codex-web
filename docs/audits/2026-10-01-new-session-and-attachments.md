# 新会话导航与附件恢复修复

## 问题与修复

- `handleLayoutResize` 将新建页面转换成会话列表或旧会话，也会隐藏尚未发送的草稿。现在保留 `new` 页面，并在窄屏中将草稿保留为聊天输入页。
- `selectProjectScope` 等待列表刷新后无条件打开项目里的最近会话。现在检查身份、导航代次及项目选择；新建、开始草稿、选择其他页面都会使旧请求失效。
- 单用户模式显示路径输入，但隐藏的 `newProjectId` 仍可能覆盖输入路径。现在单用户创建只使用路径，可信团队模式继续使用获授权的项目选择。
- 空白新会话不显示“就绪／附件已上传”等常驻状态；草稿保存失败、逐文件上传进度及错误处理保留。颜色、字体、布局和主题令牌不变。
- `startTurn` / `steerTurn` 发给 Codex 的文字含附件路径，实时 `user.message` 及持久时间线却只记录原始文字。现在记录与 Codex 输入相同的附件说明，切回会话时无需等完整历史同步才能恢复图片入口。
- 已确认消息提供附件快照路径时，以该列表替换乐观消息的临时上传路径，避免同一图片重复显示；旧版纯文字回执仍保留本地附件引用。

未修改用户历史或图片文件。截图不足以追溯当次 JEV 提问的点击过程，因此不能断言当次错投完全由哪个导航分支造成。
