# Markdown 文件预览优化

Markdown 文件改为接近 GitHub 的文档排版，正文使用会话面板的可用宽度。此次修订已替换第一版较窄的阅读栏。

## 阅读与内容结构

| 原来的问题 | 改动后的行为 |
| --- | --- |
| 一级到三级标题都是 14px，难以辨认层级 | 一级标题 32px（手机 28px）、二级 24px、三级 20px；四到六级标题正确解析，正文 16px / 1.65 |
| 编号列表合成普通段落，嵌套关系丢失 | 保留起始编号、嵌套列表、续行和段落，列表里的代码保留缩进 |
| 第一版桌面内容过窄，风格不符合预期 | 正文占满预览区可用宽度；一级、二级标题底部分隔线，简洁引用，浅底代码和边框斑马纹表格 |
| 窄屏表格被挤成很窄的列 | 单元格最小宽度 140px，宽表格在自身区域内横向滚动 |
| 长命令自动折行，原始结构不清楚 | 代码块保留换行和缩进，显示语言标签，支持局部横向滚动 |
| 连续缩放窗口会自动退出文件预览 | 保持当前文档和滚动位置；管理台只读文件继续留在观察模式 |

表格和代码区域可用键盘聚焦和滚动。沿用五种主题，链接与焦点清晰可辨。关闭预览返回会话，草稿仍在；下载仍取得原文件。

本次没有引入新的前端依赖。文档与聊天使用不同的渲染缓存键，HTML 转义、本地文件链接权限和 HTML 文件沙箱保持有效。Markdown 仍是轻量语法子集，不宣称完整兼容 CommonMark 或 GFM。
