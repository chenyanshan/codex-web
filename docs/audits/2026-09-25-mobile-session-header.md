# 手机会话顶部减法调整

用户反馈：手机 session 顶部信息太多，内容看不见；进一步明确手机不需要常驻这么多信息。

依据 frontend-design 与 OPT 保留基线。截图复现了 320px 中项目名只剩「这…」、目标英文 `Goal active` 占据第二行、重连只剩「正…」。原因是标题被返回/停止/菜单夹在中间，项目、目标、连接和计时又同时挤进其下方单个 `overflow:hidden` 行。

设计采用减法，保留既有系统字体、五主题颜色与紧凑顶栏。手机常驻仅会话标题、简短运行/连接状态、返回、Stop、菜单；桌面布局不变。完整标题、项目、目标、详细计时进入既有会话菜单，不增加新弹窗或入口。目标状态支持中文；目标正文在原生折叠项中按需展开，数千字目标不会默认把菜单操作推远。完整内容没有改成仅 hover 可读。

`runtime-feedback` 的计时使用独立 span，手机顶栏隐藏计时而菜单保留；每秒刷新覆盖所有副本。菜单副本不启用 live region，刷新时保留这一选择，避免重复播报。未修改网络恢复、暂停重试、停止执行等控制逻辑。
