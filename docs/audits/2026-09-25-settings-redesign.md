# 全局设置重设计

## 设计计划与开工前评审

主题是手机遥控本机 Codex 的偏好与服务设置。延续五主题，参考清新白的背景 #f4f5f7、导航 #eaecef、表面 #ffffff、正文 #1f2937、次要文字 #6b7280、强调 #10b981；实现只使用现有主题变量。保留系统字体和路径等宽字体，窗口标题 22px、分组标题 18px、字段 14px、说明 13px。内容左对齐。

桌面由窄小左下角面板改为视口居中对话框，背景遮罩表达已有模态行为。标题和关闭固定，左边是设备、服务、账号的导航，右边连续可滚动设置。手机沿用独立设置页，导航折为紧凑的顶部组按钮，正文单列。连续内容保留浏览器查找、所有既有设置入口和表单节点，避免标签页切换丢失草稿。

```text
             Settings                           Close
             ────────────────────────────────────────
             This device │ Appearance
             Shared server│ New sessions
             Account     │ Shared server
                         │ Account & devices
```

开工前评审：不引入新品牌、卡片堆叠、额外字体或装饰。视觉重点只放在正确的窗口层级与可读的设置层次。共享服务器与本设备范围直接说明，Webhook 真实地址仍可选择和复制；密钥默认隐藏，显示、复制、换钥分离，换钥沿用确认及异步状态。

## 实施与复评

新增 `public/settings-ui.js` 与 `public/settings-ui.css`，仅负责设置窗口和分区导航；原保存、权限和加载处理仍由 app.js/Webhook 模块负责。桌面 880px 最大宽、760px 最大高，整视口居中并有主题遮罩；手机是独立单列页面，顶部保留返回，组导航随页面固定，正文独立滚动。导航是页内跳转而非标签页，不隐藏表单。输入与下拉框在手机为 16px，避免 iOS 因小字号自动放大。

分区是本设备、共享服务器、账号。核对 `server.ts` 后确认 Webhook 按 `principal.userId` 保存，因此它放在账号区，不能误称共享配置。没有服务级能力的账号不展示空服务器组。原五主题、两布局、消息字号、语言、默认模型/推理/模式/权限、网站标题、团队开关、运行时重载、设备与退出入口保留。

Webhook 默认以密码字段显示，允许独立显示/隐藏和复制。旧 HTTP 剪贴板回退使用瞬时离屏文本缓冲，结束即移除，不把屏幕上的密码字段强制改为明文。重新打开设置重置可见状态；换钥保留原确认与异步禁用/失败反馈，成功关闭后也归还焦点。

视觉复评：与旧截图相比，设置现在与模态交互的范围一致；去掉初稿导航按钮的边框，避免每一项像独立表单按钮；手机 320px 下主题选择两列，密钥动作自行换行。844×390 横屏正文保持独立滚动，导航压缩但触摸目标不低于 40px。未改会话列表、聊天气泡或输入框。

## 优化保留映射与限制

| 编号 | 保留方式与验证 |
| --- | --- |

回退可独立恢复 app.js 设置渲染/导航绑定与 webhook-settings.js 小改动，删除 settings-ui.js/css 及其资源注册；不涉及聊天壳或后端运行底座。
