## 原因与修复

原来所有本地链接都从项目根目录解析。`docs/report.md` 中的 `images/chart.png` 被错误地查找为项目下的 `images/chart.png`，因而显示“文件不存在或已被清理”。实际文件和后端权限检查均正常。

文档内相对链接现在从当前文档所在目录解析，支持连续打开嵌套 Markdown、`../`、编码后的文件名及绝对路径。失败重试复用已经解析的路径，避免重复拼接父目录或重复解码。关闭嵌套预览仍恢复原会话的阅读位置和草稿。

聊天中的项目相对链接、分享访问规则、后端文件授权与容量限制保持原实现，无需放宽文件访问权限。
